# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/your-username/portfolio.git
```

## Install dependencies

```bash
flutter pub get
```

## Run locally

```bash
flutter run -d chrome
```

## Build for production

```bash
flutter build web --release
```
